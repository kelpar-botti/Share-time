# 会話からの受付停止候補

LINE / Discord の日程提案と合意らしい発言を、同じ会話の文脈で確認して候補を作る。
所有者が候補の日付を確認して確定するまで公開カレンダーは変わらない。見送り・未操作では変更しない。

## 操作

- 所有者は `/admin/availability` で候補、根拠の抜粋、日付の編集、確定、見送りを操作する。
- 過去の会話は「自分:」「相手:」を付けて貼り付けられる。相対日付は会話した日時の日本時間を基準に解釈する。
- Androidアプリの初回連携も同ページから行う。本人が「連携キーを作る」を押し、本人の端末に入力する。サーバーにはSHA-256のみ保存する。90日で期限切れ、管理画面から解除可能。
- Android専用アプリは `../android-companion/`。通知アクセス・通知表示権限を本人が許可する。メッセンジャーへ返信・Bot参加は行わない。

## 読み取り範囲

通知として取得できた同一会話の履歴を最大80件参照する。端末は取得済みの文脈を7日間保存し、合意の手掛かりがあるときに送信する。インストール前の会話や、通知に現れない自分の送信内容を全取得する機能はない。欠けた返信は共有・貼り付けで補う。

v1は日本語の明示日付・相対日付・同意・訂正・断りを規則で判定する。外部AIサービスへ会話を送信しない。雑談、曖昧な曜日、仮予定、日をまたぐ予定、発言者不明などは確定扱いにしない。高度な言い回しの解釈や会話の完全な理解は保証しない。

サーバーは解析に使った全履歴を保存せず、提案の説明・日付・最大2000文字の根拠抜粋を所有者専用で保存する。公開レスポンスは日付と受付停止フラグのみ。既存の予約やジョブカン取込は維持する。

## 端末API

固定接続先: `https://share-time-lyart.vercel.app/api/integrations/conversation`

`Authorization: Bearer <device-token>`。ブラウザーOriginからの呼出しは拒否。1端末30回/分、JSON最大128KiB。任意の所有者・保存先・解析サービスは指定できない。

- `POST` `{source:'line'|'discord',conversationId,messages:[{id,conversationId,sender:'self'|'other'|'unknown',text,sentAt:ISO}]}` → `{ok,analysis,suggestion?}`。
- `GET` → 所有者の確認待ち候補。
- `PATCH` `{id,action:'accept',dates:['YYYY-MM-DD']}` または `{id,action:'dismiss'}`。

同じ会話・同じ合意発言の再送は同じ提案IDとなり、見送り/確定を未処理へ戻さない。会話中の命令文はデータとして扱い、カレンダーを直接変更しない。

後から同じ会話で中止・日付や時刻の変更を取得した場合は、古い未確定候補を取り下げる。所有者専用の会話カーソルは取り下げた時点より古い再送を無効にし、古い候補の復活を防ぐ。取り下げは提案だけに作用し、確定済みの受付停止や予約を変更しない。発言者不明でも単一の日付が読み取れた場合は、低確度の候補日として表示し、本人の確認を必須とする。

## 受付停止

`dayAvailability/YYYY-MM-DD` に停止状態を別途保存する。訪問者の新規予約・時間変更と受付停止の確定は、同じ日付ガードをFirestoreトランザクションで読み書きし競合を検出する。前日からの日またぎも対象、翌日00:00終了は翌日を占有しない。既存の承認待ち予約の承認は維持し、既存予約は自動取消ししない。

確定前の日付編集と見送りに対応。確定後の解除・日付変更はこの版には未実装。自動取消しの誤検知で受付が再開することを防ぐため、会話中の取消しを根拠に既存の停止を自動解除しない。

## 検証

`npm test` の conversation-proposals / conversation-integration / day-closure / date-validation テストが、解析、専用端末認証、見送り再送、確定までの無変更、日付編集、直接予約拒否、競合、日またぎ、公開情報の限定を検証する。実際の通知取得の検証は、本人のAndroid端末へのインストール・権限付与後に別途必要。
